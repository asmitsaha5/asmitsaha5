## 🚀 Projects

### ♟️ Chess Game

A browser-based chess game built with React.

It started as a simple chess project and turned into a proper little game with an AI opponent and a bunch of actual chess rules.

**What's inside:**

* 🤖 Multiple AI difficulty levels
* 🧠 Minimax + Alpha-Beta pruning
* 🎯 Legal move validation
* ♟️ Check, checkmate, stalemate & draw handling
* ↩️ Undo & restart
* 📜 Move history
* 🔄 Board orientation
* 🎨 Multiple themes
* 📱 Responsive UI
* 🗄️ Backend API with PostgreSQL

**Stack:** React · JavaScript · chess.js · Node.js · Express · PostgreSQL

🔗 [Live Demo](https://chess-game-as.vercel.app/)
📂 [Source Code](https://github.com/asmitsaha5/chess-game)

* 🧠 Quiz generation
* 📄 Resume building
* 🔐 Google authentication
